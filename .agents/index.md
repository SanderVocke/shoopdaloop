Project-specific information (read them on a need-to-know basis):

- `info/build.md`: how to build
- `info/test.md`: the test suites and how to run them
- `info/troubleshooting.md`: common pitfalls with workarounds. read when having runtime issues running the tests or app, which seem unrelated to the task at hand.
- `info/ci-debug.md`: how to inspect CI status, jobs, logs, and artifacts with the GitHub CLI before reproducing a failure.
- `info/ci-repro.md`: techniques for reproducing CI resource-contention failures locally on Linux hosts
- `info/run.md`: how to run the app. including in development mode.

Prompts for specific tasks:

- `prompts/write_plan.md`: read when asked to write an implementation plan for a large feature or feature set.

Rules and guidelines agents should respect:

- `rules/mandates.md`: always read. contains steps/actions every agent is expected to perform in certain scenarios.
- `rules/style.md`: read before making code changes. contains coding style guidelines.
