ShoopDaLoop¶

ShoopDaLoop is a cross-platform audio and MIDI live-looping application with a graphical interface. It runs natively on Linux, Windows, and macOS and has a Web Audio/Web MIDI browser build.

For source, installation, and current project status, visit the GitHub repository.
