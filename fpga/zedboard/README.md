# Historical ZedBoard integration

The previous TP-backed ARM/control/demo implementation is retired. No current
board bitstream, host driver or control command is provided. The checked-in
archive, constraints and validation reports are historical reference material
for board provisioning and future component integration, not a working backend.

See [current architecture](../../FPGA_ARCHITECTURE.md). Do not load the old bundle
as validation of this branch's component scope.
